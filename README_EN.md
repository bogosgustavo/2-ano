## ▶️ How to run

### C

You need to have [GCC](https://gcc.gnu.org/) installed.

Inside the folder containing the file:

```bash
gcc "Lista Condicionais.c" -o programa
./programa
```

On Windows, the executable will be `programa.exe`.

### Java

You need to have a [JDK](https://adoptium.net/) installed.

Inside the project or class folder:

```bash
javac *.java
java Principal
```

### Assembly

The `.asm` files can be opened in a MIPS simulator such as [MARS](https://dpetersanderson.github.io/) or QtSpim.

### VHDL

The project files can be opened in **ModelSim** for compilation and simulation.
